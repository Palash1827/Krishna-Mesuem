# 🏛️  Krishna Museum

A full-stack web application developed for managing and exploring the Sri Krishna Museum. The project provides a user-friendly interface for visitors and an admin dashboard for managing museum artifacts.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Java
- Spring Boot
- REST API
- MongoDB

## ✨ Features

### User Side
- View museum information
- Explore museum floors
- Browse artifacts
- View artifact details
- Responsive user interface

### Admin Side
- Admin login
- Protected admin dashboard
- Add artifacts
- Update artifacts
- Delete artifacts
- View all artifacts
- Upload artifact images
